# Release notes: v0.0.1 archive

`v0.0.1` is now an archive/rollback release. Early TWRP experiments that could
not decrypt `/data`, including v17-v23 and the old `recovery.img`, were removed
on 2026-10-10 to prevent accidental downloads.

Historical digests remain in
[`../v0.0.1-assets.sha256`](../v0.0.1-assets.sha256) for audit only. The current
recommended TWRP image is
[`v0.2.0-rtyu-integration`](https://github.com/miuiadmin/twrp_device_oneplus_OP64D3L1/releases/tag/v0.2.0-rtyu-integration).
